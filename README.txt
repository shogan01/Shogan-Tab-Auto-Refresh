SHOGAN AUTO REFRESH v4.3
========================

NEW IN VERSION 4.2
------------------
- Added Recent Sites history.
- Saves each page URL and the last refresh interval used for it.
- Starting a site automatically adds/updates it in Recent Sites.
- Saved sites default to "Auto-start when this page is opened".
- When a saved exact URL loads in any tab, its remembered timer starts automatically.
- Each history entry can have auto-start turned on/off.
- "Use" loads a saved URL + timer back into the popup.
- Individual history entries can be removed.
- All saved history can be cleared.
- Stopping a tab does NOT delete its saved site history.
- Keeps the v4 background-tab refresh and v4.1 polished icon.

NOTES
-----
Auto-start matches the exact saved page URL (ignoring only the #fragment).
This avoids accidentally refreshing every page on an entire website.

For unpacked Developer Mode installations, the 5-second alarm remains available.
If the computer is asleep, Chrome cannot refresh the page until the computer wakes.

INSTALL / UPDATE
----------------
1. Extract the ZIP.
2. Open chrome://extensions
3. Remove or disable the older version.
4. Turn on Developer mode.
5. Click Load unpacked.
6. Select: shogan-auto-refresh-v4.3
7. Pin the extension if desired.

Version: 4.3.0
